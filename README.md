# PAIR.exe

윈도우 98과 뉴 밀레니엄 테마의 페어틀 편집기입니다.

## 기능

- 페어 사진과 캐릭터별 두상 사진 편집
- 페어명, 이름, 한마디, 기본 정보, 성격·설정 서술
- 텍스트 직접 클릭 편집, 개별 글꼴과 크기 지정
- 기본형 / 프로필 확장형 레이아웃
- 배경색, 테마색, 사진 영역 크기·배율·위치 조절
- PNG 내보내기와 프로젝트 저장·불러오기

## 실행

빌드가 필요 없는 정적 HTML·JavaScript 앱입니다. 저장소 루트를 GitHub Pages의 게시 소스로 지정하면 됩니다.

사진과 편집 내용은 브라우저에서 처리됩니다. 자동 저장 내용은 브라우저와 접속 주소별로 구분됩니다. 기존 주소에서 작업하신 내용은 프로젝트 JSON으로 저장한 뒤 새 주소에서 불러오실 수 있습니다.

## 글꼴

글꼴은 `fonts/`에 포함되어 있습니다. 각 글꼴의 라이선스는 같은 폴더의 OFL 및 LICENSE 파일에서 확인하실 수 있습니다.
